# MIT Moradabad Website

A simple, responsive, multi-page informational website project built with HTML and CSS.

## Pages
- `index.html` — Home page
- `about.html` — About the institute, vision, and mission
- `departments.html` — Academic departments
- `admission.html` — Admission information and official resource link
- `institute.html` — Institute overview

## Run locally
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the **Live Server** extension in VS Code.

No build tools, Java, or dependencies are required.

## Project structure
```text
website/
├── index.html
├── about.html
├── departments.html
├── admission.html
├── institute.html
├── style.css
├── README.md
└── .gitignore
```

## Notes
- This is a student project website and is not an official MIT Moradabad website.
- Images are loaded from external URLs and therefore require an internet connection.
- Admission requirements and academic offerings may change. Refer to the official institute website for current information.
